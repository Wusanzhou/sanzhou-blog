# 三舟的编程笔记

> AI 编程学习记录 — 用 VitePress + GitHub Pages 构建

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview  # 预览构建结果
```

## 内容结构

- `docs/guide/` — 🚀 入门指南
- `docs/practice/` — 🔨 实战项目
- `docs/tools/` — 🛠️ 工具与效率
- `docs/deep-dive/` — 🧠 深入理解
- `docs/notes/` — 📝 踩坑笔记

## 技术栈

- [VitePress](https://vitepress.dev/) — 静态站点生成器
- [GitHub Pages](https://pages.github.com/) — 托管与部署
- [GitHub Actions](https://github.com/features/actions) — 自动构建部署
