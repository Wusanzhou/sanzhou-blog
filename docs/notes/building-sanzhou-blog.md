# 博客搭建全记录：用 AI 花一个晚上从零到上线

> 2026-06-07 开发日志 — 记录了使用 Claude Code + VitePress 搭建「三舟的编程笔记」的完整过程。

## 动机

一直想有个地方记录 AI 编程学习过程。传统博客框架太重，想试试完全用 AI 来搭——我只给方向，AI 写代码。

## 第一阶段：方向规划（5 分钟）

我把想法告诉 AI：「想建一个个人技术博客，部署到 GitHub Pages，记录 AI 编程学习。」

AI 给出了完整的大纲：

- **技术选型**：对比了 VitePress / Hexo / Hugo / Next.js，最终选 VitePress（Node.js 现成、Markdown 写作、GitHub Pages 天然支持）
- **内容结构**：5 个板块——学习路线、练习项目、工具笔记、理解笔记、问题记录
- **部署方案**：GitHub Actions 自动构建 + GitHub Pages

我确认了几个偏好：中文为主、随时记录、博客名叫「三舟」。

## 第二阶段：项目搭建（10 分钟）

AI 一次性完成了：

整个过程我一行为没写。初始化、装依赖、创建目录、写配置文件、写占位页面，全自动。

## 第三阶段：主题美化（30 分钟）

默认的 VitePress 蓝紫配色感觉太冷、UI 太"古老"。我说想要"暖色调、积极阳光"。

AI 做了三件事：

### 1. 自定义 CSS 变量

把 VitePress 的 30+ 个 CSS 变量全换成了暖色系：

| 元素 | 默认（冷蓝） | 改为（暖橙） |
|------|-------------|-------------|
| 品牌色 | `#3451b2` | `#e67e22` |
| 背景 | 纯白 | `#fffdf7` 奶白 |
| 文字 | `#1f1f1f` | `#3e2f1c` 暖棕 |
| 边框 | 冷灰 | `#f0e6d3` 暖杏 |

暗色模式也做了对应的暖色调适配。

### 2. 首页目录卡片

用 Vue 组件做了 5 张彩色卡片，每张对应一个板块，点击直达：

```
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 学习路线 │ │ 练习项目 │ │ 工具笔记 │
└──────────┘ └──────────┘ └──────────┘
┌──────────┐ ┌──────────┐
│ 理解笔记 │ │ 问题记录 │
└──────────┘ └──────────┘
```

hover 浮动 + 箭头滑动，交互感比默认的 feature grid 好很多。

### 3. 页面切换动画

这是最有趣的部分。常规的页面切换太生硬，AI 帮我用 View Transitions API 做了 6 种随机动画：

| # | 动画 | 效果 |
|---|------|------|
| 🏀 | bounce | 从左上角砸下来，弹三下回正 |
| 🌀 | spin | 从远处旋转 720° 飞入 |
| 💥 | pop | 从针尖大小爆开再弹回 |
| 🚀 | slide-up | 从底部弹上来，弹簧过冲 |
| 🃏 | flip | 3D 翻牌，旧页翻走新页翻入 |
| 🍮 | jello | 果冻摇晃着出现 |

每次点击随机选一种，相邻 3 次不重复，像开盲盒。

**技术细节**：在 VitePress 的 `setup()` 里用 `capture: true` 拦截所有内部链接点击，调用 `document.startViewTransition()` 包裹 `router.go()`。翻牌动画遇到过中点卡顿的 bug，原因是新旧两页同时在 45° 交错——把时序错开（旧页先翻走、新页再翻入）就解决了。

## 第四阶段：部署与踩坑（15 分钟）

### 坑 1：GitHub Pages Source 没配

Workflow 报 `Get Pages site failed`。去 Settings → Pages → Source 选 **GitHub Actions** 解决。

### 坑 2：HTTPS Push 失败

终端 push 时挂起，后来发现是 credential 问题，在系统终端里手动 push 搞定。

### 坑 3：base 路径

线上打开完全没有样式（白底黑字）。原因是 GitHub Pages URL 是 `wusanzhou.github.io/sanzhou-blog/`，多了一层路径 `/sanzhou-blog/`，VitePress 默认 base 是 `/`，所有 CSS/JS 请求 404。

`config.ts` 加一行解决：

```ts
export default defineConfig({
  base: '/sanzhou-blog/',  // ← 这一行
  // ...
})
```

### 坑 4：CDN 缓存

base 改完后第一次打开还是没样式，刷新就好了。GitHub Pages CDN 有短暂缓存，几分钟后自动消失。

## 感悟

### AI 做得好的

- **初始化飞快**：从零到可运行的博客，不到 5 分钟
- **配置完整**：导航、侧边栏、搜索、中文化、暗色模式，覆盖全面
- **有创意的设计**：我说"暖色调 + 动画有意思一点"，AI 直接做了 6 种随机效果，超出预期
- **debug 能力强**：翻牌卡顿、base 路径、CDN 缓存，每个问题都能快速定位和修复

### 需要人工判断的

- **博客名称、定位、内容大纲**：AI 是执行者，方向需要自己想
- **审美判断**：动画太快、太晃眼——这些主观感受需要人来反馈
- **push 权限**：涉及 GitHub 认证的操作，AI 帮不上，得自己来

### 整体感受

用 AI 搭博客的效率是传统方式的 **10 倍以上**。更重要的是，整个过程像对话一样自然——我说想法，AI 实现，我反馈，AI 调整。这不是"写代码"，这是"聊出一个产品"。
