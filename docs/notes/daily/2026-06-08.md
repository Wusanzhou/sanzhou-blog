## 做了什么

### 开发了「定时经验总结」安装包 v1.0.0

为 Codex 做了一个自动经验复盘功能的安装包，让 Codex 能**定期回顾近期协作记录，把可复用的经验沉淀到本地持久层**。

提交：`9270f99` — `feat: 添加功能-定时经验总结`

### 核心机制

| 维度 | 设计 |
|------|------|
| **调度** | 每天北京时间 18:00 自动运行一次 |
| **持久层分级** | 偏好 → `AGENTS.md`，工作流 → `skills/`，状态 → `vault/`，回归案例 → `evals/`，权限边界 → `rules/`，校验检查 → `hooks/` |
| **降噪门控** | 高置信度（重复出现 / 用户明确要求 / 造成过明显错误）→ 直接写入；中置信度 → 进入候选列表；疑似敏感 → 不落盘 |
| **游标策略** | `memory.md` 为主连续记忆，`lesson-review-cursor.json` 为机器可读 canonical cursor |
| **安全边界** | 维护目录位于 `$CODEX_HOME` 内，安装包不携带发送方历史记录 |

### 亮点

- **多层持久化架构** — 经验按类型分别路由到 6 种持久层，避免混在一起难以维护
- **降噪优先** — "宁可漏掉弱经验，也不要把噪声写进长期记忆"，只沉淀真正有价值的
- **安装友好** — 支持 `--dry-run` 预览、`--paused` 暂停、`--upgrade` 升级，多仓库监听
- **人机协作** — 候选经验和待确认变更统一放在 `maintenance/` 目录，方便人工审查

### 收获

- 从"用 AI 写代码"升级到"教 AI 自我成长"——让 Codex 的协作经验不随着聊天记录消失
- 持久层分级的设计思路可以复用到其他自动化场景
- 降噪门控是个正确的取舍：精准比全面更重要
