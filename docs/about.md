# 关于三舟

## 我是谁

一个正在学习 AI 编程的程序员。三舟是我的笔名。

## 这个博客是干什么的

记录我在 AI 编程学习路上的所见、所思、所做。

AI 编程工具变化很快，我自己也还在摸索。这个博客主要是给自己留一份学习轨迹：哪些东西试过，哪里理解错了，哪些做法后来证明有用。

## 写什么

- **学习路线** — 我给自己整理的基础概念和学习顺序
- **练习项目** — 我实际做过的小项目和过程记录
- **工具笔记** — 使用 AI 编程工具时记下来的做法
- **理解笔记** — 对机制和概念的阶段性理解
- **问题记录** — 踩坑、返工和后来想明白的地方

## 使用的工具

- **编辑器**：VS Code
- **AI 助手**：Claude Code、Cursor
- **博客框架**：[VitePress](https://vitepress.dev/)
- **部署**：GitHub Pages
