# 关于三舟

## 我是谁

一个正在学习 AI 编程的程序员。三舟是我的笔名。

## 这个博客是干什么的

记录我在 AI 编程学习路上的所见、所思、所做。

这个时代，AI 正在深刻改变写代码的方式。从最初的自动补全，到现在的 Agent 自主编程，变化太快了。我想把这些学习过程记录下来，既是对自己的总结，也希望对同样在这条路上的人有所帮助。

## 写什么

- **入门指南** — 面向刚接触 AI 编程的朋友
- **实战项目** — 真实项目中使用 AI 的完整过程
- **工具效率** — 工具的高级用法和效率提升
- **深入理解** — 原理层面的理解和思考
- **踩坑笔记** — 失败的经验比成功的更有价值

## 使用的工具

- **编辑器**：VS Code
- **AI 助手**：Claude Code、Cursor

- **部署**：GitHub Pages
