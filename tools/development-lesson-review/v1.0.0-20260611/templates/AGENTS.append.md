## Durable Memory Layers

不要依赖聊天历史保存重复使用的知识：

- 重复出现的偏好放到全局或项目内 `AGENTS.md`。
- 重复执行的工作流放到 `skills/`。
- 项目或环境状态放到 `vault/`。
- 不应回归的失败案例放到 `evals/`。
- 权限和访问边界放到 `rules/`。
- 确定性的校验逻辑放到 `hooks/`。

出现新的持久信息时，选择最窄且匹配的持久层。条目保持简短；有助于追踪时标注日期；内容应容易验证。

## Durable Summary Language

自动经验总结和持久指导更新中，正文内容（规则、边界、经验说明、分层理由、校验说明等）使用中文书写，方便后续审查。必要的文件名、标识符、技术术语、章节标题或简短简介可以继续使用英文。
